# Job Portal

## Active applications

- `Client/` is the active Vite frontend.
- `Job--portal-backend/` is the Express and MongoDB backend.
- Start the frontend from `Client/` with `npm run dev`.
- Start the backend from `Job--portal-backend/` with `npm start`.

## Legacy frontend

`Job--portal-backend/frontend/` is an older Create React App copy kept for reference. Do not use it for current development; use `Client/` instead.

## Local URLs

- Frontend: `http://localhost:3000`
- Backend API: `http://localhost:5000`
